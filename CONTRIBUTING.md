# Contributing

Thank you for helping FreshLoop make thoughtful food use easier. Open an issue before a large change. Keep features usable without paid services, label uncertainty honestly, and never weaken household isolation in future server work.

1. Create a focused branch.
2. Run `npm test` and `npm run check`.
3. Test the main flow at narrow and wide viewport sizes.
4. Explain user-facing, privacy, accessibility, and data-model effects in the pull request.

Use clear commit messages. New behavior needs meaningful tests. Do not commit secrets, user data, unlicensed recipes, or generated claims about food safety.
